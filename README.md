# Discord Ticket Bot 🎫

A lightweight and customizable Discord support ticket bot built with `discord.py`.

## ✨ Features

- 🎫 Ticket creation with dropdown menu
- 🛒 Purchase & Information
- 🛠️ Technical Support
- 🔄 Upgrade & Renewal
- 📄 Refund & Complaint
- 🔒 Close tickets with a button
- 📝 Automatic ticket transcripts
- 📩 Send transcripts to users via DM
- ⏰ Automatic inactive ticket closing
- 🚫 Prevent duplicate open tickets
- 🔐 Environment-based configuration

## 📋 Requirements

- Python 3.10+
- Discord Bot
- `discord.py`
- `python-dotenv`
